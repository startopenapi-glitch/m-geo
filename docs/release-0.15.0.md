# M-GEO 0.15.0 源码更新

更新日期：2026-10-24。

主分支已更新至 0.15.0 源码。此更新覆盖截至第十四阶段的本地商品优化工作流，包括商品事实与内容审核、目录草稿、归因和批量运营、离线优化诊断、历史报告/通道证据复核，以及按商品、问题和平台查看配对推荐变化。

## 本地验证

本地验收使用虚构商品和模拟数据。记录覆盖 Rust 359 项、前端 263 项测试、格式化/类型检查/桌面全目标 Clippy，以及原生窗口中的保存、回读、分页、导出和重开流程。Apple Silicon macOS 本地 DMG 的签名结构和只读挂载也已检查。

这些检查不代表远程 CI、真实平台登录、真实商品效果或线上发布已通过。测试夹具和本机验收资料不随本次源码更新公开。

## 已知边界

- 应用不会自动发布或抓取内容，也不保证 AI 首页推荐、索引、排名、流量或销量。
- 模型服务由使用者配置。保存配置不会请求模型；用户主动测试/生成时，所选内容会发送给该服务，可能产生费用。
- 本更新仅发布源码。此仓库目前没有 v0.15.0 二进制安装附件；Releases 中最后公开的预编译版本仍为 v0.1.1。
- 本地 Apple Silicon DMG 使用 ad-hoc 签名，未完成 Apple Developer ID 签名或公证；Windows/Intel 0.15.0 安装包未发布。
- 0.15.0 工作区与更早版本的数据格式可能不兼容。不要使用旧版程序打开较新版资料；回退前先阅读备份说明并保留当前快照。
