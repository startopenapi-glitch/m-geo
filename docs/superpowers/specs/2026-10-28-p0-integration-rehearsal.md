# P0 接入演练 0.21.0

用户已批准上一轮 P0 优先级，并要求先完成不依赖真实官网和账号的部分，虚构商品和模拟数据验收，子 agent 并行推进。本规格把这项授权具体化，不再扩展到 P1/P2。

## 目标与界限

复用现有商品事实、原生稿件审核和隔离工作区，新增可持久化的 P0 接入演练。分开自然发现与带资料问答；把模拟监测、候选稿、人工审核、单独的模拟发布批准、模拟 CMS 回执、页面核验与复测串成可暂停、可追溯的任务。

- 正式 `/Applications/M-GEO.app` 0.20.0、正式数据目录与模型配置不修改。
- 新候选为 0.21.0，独立 Bundle ID、独立虚构数据；不覆盖正式 App。
- 新执行链只有 `fixture` 适配器。没有网络、模型、钥匙串、账号或公开发布调用；传入真实传输类型必须拒绝。
- 所有样本、CMS 页面、回执、成本均标模拟。模拟费用单位不是人民币；实际网络请求、模型调用、公开发布计数始终为 0。
- 现有单次真实模型功能不调用、不自动串入；其 UI 明确标为带资料问答测试。
- 原生审核为唯一内容审核关卡。模拟发布批准单独绑定目标 URL、商品版本、稿件版本、正文摘要；改动后不得沿用。
- 不新增依赖、不无关重构，保留 AGPL/GEOFlow/第三方署名。

## 方案与范围裁定

复用 0.20 的安全基础，但新增 `p0Workflow` 任务类型，避免改变已导出的离线任务证据语义。真实连接器在本轮不可选；通过模拟传输契约和故障场景验证未来接入所需的边界。系统后台调度、真实站点渲染、真实平台推荐与真实账号交付留待后续授权。

新增导航“AI 测试 → 接入演练”。每任务一件已确认商品、一个固定问题、一个 `.invalid` HTTPS 模拟地址。固定顺序 baseline → generate → audit → review → publish → readback → followup。离开页面可由原生 worker 推进；退出/睡眠不运行，重开和恢复后暂停，不补跑。

## 核心能力

1. `natural_discovery` 请求只含中性问题，不注入品牌、别名、完整商品名或商品事实；`informed_qa` 明确包含已确认公开事实。人工消费者记录、搜索 API 与带资料 API 的概念在 UI 分开；本轮输出来源始终是 fixture，不能伪装成真实 API/平台。
2. 可预览模拟请求，明确 contextIncluded。自然问题拒绝显式品牌/别名/完整商品名；不保证不存在所有暗示。基线和复测重放相同 fixture，差值不是优化效果。
3. 跨节点任务预算与工作区每日模拟预算、调用次数、全局急停；确定性 ledger、操作 ID、重复请求幂等；429 限次退避；发布响应未知时禁止盲重试，先对账，不重复建页或计费。
4. 模拟 CMS 保存草稿预览、发布版本、远端 ID、URL、回执和正文摘要。首次发布前必须原生审核且单独批准。支持恢复模拟发布前的版本（首次发布则回到未发布），保留回滚记录。
5. 对输入的模拟 HTTP 响应/HTML/robots/sitemap 检查 HTTP 可读、目标与最终 URL、正文一致、title/description/H1、noindex、robots 限制、canonical、sitemap 及 JSON-LD。全部仅解析文本，不执行脚本、不访问 URL；分别显示检查结果，不宣称已收录。
6. 证据 ZIP 包含固定请求模式、任务/节点/ledger、模拟回执、检查报告及已审核稿件；导出前后再次核对版本，取消不改变任务。新结构参加严格数据库校验、加密备份、恢复及升级前快照。

## 验收

- 虚构商品完成完整流程，两个人工关卡均不可绕过；真实资料无新记录。
- 自然/带资料请求隔离，模拟身份不可伪造。
- 超预算停止、跨任务日限额、全局停止、429 限次、未知结果对账不重复、副本恢复暂停、过期批准拒绝。
- 模拟发布正文/抓取策略异常分别阻断或报告，回滚可核对。
- 原生窗口完成创建、审核跳转、批准、完成、导出保存/取消、重开恢复与最小窗口可用性。
- 全部 Rust/前端测试、类型检查、格式检查、生产构建、独立候选签名/打包；本轮所有未验收项如实记录。
