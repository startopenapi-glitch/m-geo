# M-GEO 0.20.0 本地自动化验收范围

用户已明确选择沿用 M-GEO、先完成不依赖官网和账号的部分，并授权子 agent 并行实施。此文记录该已授权范围，不增加上线或真实模型权限。

## 目标
把已确认商品、无品牌固定问题、模拟基线、本地结构化候选稿、离线 HTML 检查、人工审核、模拟复测和本地证据导出串成可暂停、恢复、取消的持久任务。保留现有事实审核与稿件导出资格。

## 约束
- 新功能仅支持 simulated / fixture；拒绝真实 API、网页采集、URL 抓取、发布、任意命令。
- 不读取钥匙串或实际密钥，不读取输出 key_ref；正式数据库只读做计数、业务哈希与非敏感配置核对。
- 正式 /Applications/M-GEO.app 不覆盖；使用不同 Bundle ID 的 0.20.0 候选和空白隔离数据。
- 不迁移大型外部服务栈，不增加第三方依赖。参考已调研开源架构但本轮独立实现小型本地模块，保留既有 AGPL 与 GEOFlow 署名。
- 所有自动生成内容仍为待审核；不得自动批准事实、稿件或发布。
- 任务在桌面进程运行期间执行，独立于页面可见性；退出或系统睡眠期间不运行，重启把未完成 running 任务暂停，用户明确继续。不是系统后台定时服务。

## 数据与任务
新增 schema 9 的 m_offline_workflows 表，包含品牌隔离、请求幂等、版本号和有界 JSON。升级、备份、恢复和严格验证均覆盖；旧版 schema 8 可升级，升级前建立快照。正式资料本轮不升级。

固定 DAG：baseline → rewrite → audit → review → followup。review 节点检查普通稿件原生审核状态；未审核停 awaiting_review。每次 tick 最多推进每任务一个节点，节点和稿件写入在同一事务内。任何阶段发现商品事实版本变化就失败并提示新建任务。

创建任务默认为 paused；用户点击开始/继续后本地 worker 推进。支持 pause/resume/cancel/retry；失败重试不重做已完成节点或重复生成稿件。列表最多 100 项，问题最多 10 条、每条 500 字、重复 1–3 次、样本预算最多 60；两轮所需样本超过预算拒绝创建。问题不能包含品牌名称、别名、完整商品名，品牌资料仅供模拟回答构造和本地判分，问题请求中不携带商品事实。

模拟回答必须明确标识，不写入真实 observation，也不制造真实发布记录。基线与复测默认使用同一确定性夹具，差异为零，不虚构增长。保留问题、回答、样本来源、模拟引用、判分及版本。调用/联网/发布计数恒为零。

本地改写只对已核验公开事实进行结构整理，不做语义模型改写、不生成价格/销量/功效/引用。完整保留原主张文字和事实关联，经现有审核页核对后方可导出稿件。

离线检查仅解析有界 HTML 字符串，不渲染执行 HTML、不联网读取链接：标题、description、h1、正文、结构化 JSON-LD 语法及商品一致性提示。结果为本地规则检查，不代表可抓取、收录或引用。任意输入检查可在页面预览；流水线检查其生成候选的转义 HTML。
