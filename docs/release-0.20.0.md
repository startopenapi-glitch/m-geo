# M-GEO 0.20.0 本地自动化候选

本版把确认商品后的本地工作串成持久任务：模拟基线 → 公开事实结构整理 → 离线 HTML 检查 → 人工审核 → 模拟复测 → 证据 ZIP。新增功能没有真实模型、网络抓取或发布传输，也没有新增第三方依赖；既有 AGPL-3.0-only、GEOFlow 与第三方署名继续保留。

## 操作流程

1. 录入虚构商品，为公开事实提供来源，审核并确认当前商品版本。
2. 打开“AI 测试 → 本地自动化”，选择商品，填写不含品牌、别名或完整商品名的固定问题，设置重复次数与两轮样本预算。
3. 创建后任务保持暂停；明确开始后，原生执行器按固定顺序推进。可暂停、取消或重试失败任务，重复请求不生成第二份候选稿。
4. 到人工审核节点暂停。前往“内容审核”，核对候选正文与事实主张，人工审核后回到任务点击继续。
5. 完成后导出本地证据 ZIP，包含模拟样本、规则检查、任务记录和已审核的 Markdown / HTML。保存对话框结束后会再次检查审核与商品版本，取消不会删除任务。

## 边界

- 所有监测结果为 `simulated / fixture`。两轮使用相同的冻结模拟夹具，零差异用于流程验收，不代表平台效果或优化增益。
- 本地结构整理保留原公开事实主张；不进行模型语义改写，不自动审核，不创造价格、销量、功效或引用。
- 离线 HTML 检查仅解析最多 256 KiB UTF-8 文本；不渲染脚本、不访问链接。结果不能证明网站可抓取、收录或引用，商品一致性仍须人工检查。
- 原生任务在桌面进程存活期间推进，离开页面不影响执行。退出、睡眠期间不执行；重启和恢复备份后未完成的运行任务暂停，必须明确继续。这不是系统后台定时服务。
- 既有真实模型和 URL 回读功能仍需各自明确操作；本轮不调用它们，也不连接真实平台账号。

## 数据与交付

Schema 8 升级至 9，新增 `m_offline_workflows`，包含严格的任务、预算和证据校验。升级前自动保存同目录快照；加密备份包含任务但不包含模型配置或密钥。运行中的目标工作区须先暂停任务才能恢复备份，恢复后的任务不会自动启动。

本轮候选使用独立 Bundle ID `com.mantou.mgeo.offline20261028` 和隔离虚构数据，不覆盖正式 App。正式 0.19.0 资料仍使用 schema 8。新版 schema 9 不可交给旧版程序打开；需要回退已升级工作区时，应先退出程序，同时恢复匹配版本的资料和 App。

具体构建、测试、原生验收结果及本地交付路径，以随包的验收报告为准。此版本未公开发布，未进行 Apple 公证、Windows / Intel Mac 实机验收或外部 AI 平台效果验证。
