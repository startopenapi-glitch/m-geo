# M-GEO 0.1.1 — 公开测试版

发布日期：2026-10-17。本次公开分发已有 0.1.1 内测二进制，产品运行源码与内测版一致；整理了公共说明、忽略规则、隐私与版权文档，并使浏览器验收脚本不依赖开发者本机绝对路径。

## 本版内容

- 独立桌面、多品牌、商品事实确认、客户问题、草稿审核导出、发布登记、国内四平台观察。
- 恢复候选先解密并校验，再留存安全快照并原子替换，错误口令不创建多余快照。
- 空安装和可读但业务记录损坏的工作区可直接恢复；恢复期间锁定导航，完成后清空旧请求并重载资料。
- Windows GUI 主程序与安装器／卸载器统一 Logo，附静态验包和本机验收脚本。

## 验证与边界

0.1.1 验证：Rust 68 项、前端 29 项、Windows 验包回归 6 项通过；类型检查、前端生产构建与密钥扫描通过。Mac ARM 原生备份、取消、错误口令保护、自动快照回退、重启持久、空安装和坏 JSON 救援已实际操作验证。具体公开版复跑记录见 `docs/public-release-checks.md`。

**未验证：** Windows 实际安装／运行、Windows 凭据库与 DPI、Intel Mac、签名公证、真实模型服务和真实平台发布。Windows 包为交叉构建的 x64 NSIS 安装器；缺少 WebView2 时需要联网下载运行时。请不要关闭系统保护来强行安装。

## 数据与回退

不需要业务数据库迁移，SQLite schema 仍为 1。升级前关闭应用并先导出加密备份；覆盖应用不应删除资料。若需回退，使用旧版应用及对应备份，先保留本版安全快照。物理损坏、不可读或未知 schema 的数据库可能需要人工救援。

## 下载与源码

- Mac：Apple 芯片 ARM64 DMG。
- Windows：x64 NSIS EXE。
- 对应源码：`m-geo-0.1.1-source.tar.gz`；安装包散列见 `SHA256SUMS`。
