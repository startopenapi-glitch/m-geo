# M-GEO 0.21.0：开发与使用说明

M-GEO 是本地优先的电商商品 GEO 桌面工作台，使用 Tauri 2、React 19、TypeScript、Rust 与 SQLite。当前目录提供 0.21.0 测试候选源码；已公开的预编译安装包以 [仓库 Releases](https://github.com/startopenapi-glitch/m-geo/releases) 实际内容为准，本候选未公开发布。

## 开发环境与运行

本地验证使用 Node 24、pnpm 11.25.0 和 Rust 1.99.1。macOS 需要 Xcode Command Line Tools；Windows 需要 Microsoft C++ Build Tools、Windows SDK 与 WebView2。

```sh
cd apps/m-geo
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
cargo test --locked --manifest-path src-tauri/Cargo.toml
cargo clippy --locked --manifest-path src-tauri/Cargo.toml --features desktop --all-targets -- -D warnings
pnpm tauri dev
```

构建桌面包：

- macOS Apple Silicon：`pnpm tauri build --bundles app`，之后可运行 `bash scripts/package-macos.sh` 制作本地 DMG。ad-hoc 签名不等同于 Developer ID 签名或 Apple 公证。
- Windows：在 Windows 构建机执行 `./scripts/build-windows.ps1`（需要 Python 和 7-Zip）。跨平台脚本 `scripts/build-windows-cross.sh` 需要额外配置 cargo-xwin、LLVM 和 NSIS。
- Intel Mac：安装 `x86_64-apple-darwin` Rust target，再以该 target 构建。0.15.0 的 Intel Mac 和 Windows 安装包没有随本次源码更新发布。

发布和验证边界见 [0.15.0 源码说明](../../docs/release-0.15.0.md)。本地构建不代表远程 CI 已运行。

## 使用流程

1. 创建品牌并录入商品资料。每条事实记录来源、公开范围、有效期、审核状态、更新时间和审核时间；内部信息应标为私有。新增事实默认待审核，已审核事实的名称、内容、来源、公开范围或有效期一旦修改，就自动回到待审核。
2. 逐条审核公开事实和购买信息，再确认当前商品版本。待审核或已驳回的公开事实、缺少来源及过期事实都会阻止确认。
3. 在“事实与证据 → 知识库”人工粘贴 Markdown 或纯文本资料，记录来源、关联商品、生效日期和风险等级；本地确定性切片后可查看正文、切片及审核历史。文档默认待审核，驳回必须填写理由；重复提交使用请求幂等保护。修订文档会保留 ID、创建时间和历史，重新切片并回到待审核，旧审核不会沿用。内容编辑器的“知识召回（只读）”可检索当前品牌已审核的通用及当前商品知识，按确定性关键词评分返回最多 20 个切片，并展示文档审核版本、来源、切片序号和 SHA-256；它不是 AI 语义检索，不会自动插入正文、生成事实或批准稿件。知识审核不替代商品事实审核，也不会直接生成或批准稿件。当前不支持文件上传、DOCX、URL 抓取、Embedding 或自动事实抽取。
4. 在“事实与证据 → 内容资产”人工维护关键词和标题，记录来源与可选关联商品。创建后须人工审核，修订会生成新修订、保留完整历史并回到待审核；驳回必须填写理由。可归档不再主动使用的资产并记录说明，之后可恢复；归档不是物理删除，不清除资产、审核历史或稿件快照，归档期间禁止修订、审核及新稿使用。恢复只还原可用状态，不等于重新审核。这些资产仅供人工复用，不是商品事实，不会自动进入稿件或对外发布。
5. 用通用模板编写本地草稿，或一次选择京东、天猫、抖音、视频号／微信小店、小红书、快手、唯品会中的一至七个渠道模板批量生成独立本地草稿。渠道模板只格式化已审核公开事实，保留主张与事实依据，不调用模型或平台账号；生成后仍须逐篇核对、编辑和审核。也可在设置中保存模型服务配置后主动生成通用 AI 候选内容。编辑器可将已审核标题用于标题、将已审核关键词插入正文；只关联而未实际使用、资产未审核或商品归属不匹配都会阻止审核。AI 草稿和没有主张记录的旧稿须先人工补充正文原文与公开事实的关联。缺少来源、事实未审核、关联私密事实或主张不在正文中都会阻止审核。审核通过时，原生层为每条主张冻结事实快照，并为实际使用的资产冻结文本、来源、审核版本和时间；内容资产不能替代商品事实依据。本地内容质检实时显示证据覆盖、阻断缺口与人工复核提示，但不替代原生审核门禁。
6. 将审核后的内容复制或导出，在目标渠道自行人工发布；之后再登记真实发布网址。Markdown/HTML 导出附带审核时冻结的公开主张依据和内容资产快照，导出时再次校验事实、资产历史、快照与稿件审核状态；修改正文、主张或资产关联会撤销审核并清除旧快照。发布版本台账展示商品、SKU、发布稿件版本、当前稿件版本和本地复核状态。用户可逐条主动回读公开 URL，保存有限的响应元数据并标记在线、内容变化或无法访问；系统不会自动抓取，回读不代表平台已收录或推荐。撤回仅是人工登记，不代表远端页面或平台缓存已经删除。
7. 在“品牌与问题研究”维护品牌别名、主体与官网资料，并以来源和日期登记人工或导入的研究问题；确认后可转入固定问题集。“图片与视频”保存有界媒体、来源和权利说明，审核后才可复用；内容编辑器的 GEO 规则包提供本地质量检查和公开信源渠道说明，不自动补造事实。
8. 在豆包、元宝、千问、百度等消费者入口手动查询，保存回答、引用和核对结论。也可在已有固定计划、模型配置和明确确认下主动调用真实 API；原生准备摘要、返回模型、请求标识和结果身份会一并保存，普通手工录入不能伪装成接口结果。模拟、手工和接口证据分开呈现，事实准确性仍需人工复核。
9. “巡检与趋势”支持事实到期、发布回读到期和复测缺失的只读 DAG 任务。仅在本页打开且可见时每分钟检查一次，不补跑、不在系统后台唤醒、不调用模型、不抓取 URL、不发布；趋势只描述现有样本差异，不推断因果提升。

10. “AI 测试 → 本地自动化”将已确认商品串成模拟基线、本地结构化候选稿、离线 HTML 检查、人工审核、模拟复测和本地证据包。创建后任务暂停，明确开始才执行；到审核节点暂停，须到内容页人工审核后回来继续。任务由桌面进程执行，不依赖页面可见性；退出、系统睡眠时不运行，重开或恢复备份后运行中的任务暂停，不补跑。问题不得带品牌、别名或完整商品名；预算控制两轮模拟样本总量。页面始终标明零模型、零联网、零发布；两轮使用同一确定性夹具，零差异仅用于流程验收。离线 HTML 检查仅解析粘贴的有界文本，不执行脚本或抓取链接，不能证明搜索可见度。

M-GEO 不自动登录或发布到外部平台；不会把本地导出误记成已上线，也不承诺首页推荐、收录、排名、流量或销售结果。公开 URL 仅在用户逐条主动回读时访问，真实模型 API 仅在配置有效且用户明确确认后调用。

## 数据与模型

- macOS 默认工作区位于 `~/Library/Application Support/com.mantou.mgeo/`；Windows 路径由 Tauri 的用户数据目录确定，可在设置中查看。
- SQLite 数据库本身不宣称加密。工作区通常只供当前系统用户使用；单机多品牌不提供多人协作权限。
- API Key 存在操作系统凭据库中。保存配置不会调用模型；主动测试、生成或真实监测时，所选公开商品资料和问题可能发送至用户选择的服务并产生费用。
- 加密备份覆盖工作区数据、研究记录、媒体 BLOB、巡检和本地自动化任务，不包含模型配置、API Key 或临时 AI 任务。恢复会替换整个工作区，请在升级或恢复前先保留当前备份。
- 0.15.x 及更早版本中缺少独立审核字段的事实，沿用其历史商品确认状态，不会伪造新的审核时间；任何实质修改都会进入逐条审核流程。0.19.0 将 schema 从 7 升至 8，新增研究、媒体和巡检结构，初始化、升级和恢复均校验新结构；升级前保留同目录快照，升级与恢复测试仅使用隔离的虚构资料。
- 0.21.0 将 schema 从 9 升至 10，新增 P0 接入演练及模拟预算策略。升级前建立快照；重开、恢复后任务暂停。此次隔离候选使用 Bundle ID `com.mantou.mgeo.p020261028`，不覆盖正式 0.20.0 App 或迁移正式资料。
- 「AI 测试 → 接入演练」串联模拟请求、候选稿、原生审核、独立模拟发布批准、模拟 CMS 回执、回读及复测；额度只计模拟单位，实际调用与公开发布均为 0，详见 [0.21.0 说明](../../docs/release-0.21.0.md)。
- 数据格式会随版本演进。新版工作区不要再用旧版程序打开；若需回退，应使用适配版本的备份恢复流程。卸载应用不会主动删除本地资料。
