# M- GEO 0.1.1 Windows 内测步骤

本轮目标：Windows 11 x64。安装包未做发行商代码签名；只用于此次内测。安装器需要系统 WebView2；若机器缺少它，安装器会联网下载引导程序。本包未包含离线 WebView2。

用测试品牌和测试商品操作即可，不需要真实客户数据或模型 Key。把每一步记录为“通过 / 失败 / 未测”，遇到失败保留当时页面、提示原文和操作顺序。

## 先做这 6 步

1. 运行 `M-GEO-0.1.1-windows-x64-internal-setup.exe`，记录是否出现 SmartScreen、未知发行商或杀毒拦截；不要关闭系统保护。安装为当前用户。
2. 从开始菜单打开 `M- GEO`。核对原始蓝白 Logo、标题和设置里的 `0.1.1`，确认没有额外黑色控制台窗口。
3. 新建“Windows 内测”品牌和一个测试商品，保存公开事实、确认事实；退出应用，再打开，确认商品还在。
4. 下载 CSV 模板，使用包含中文和空格的文件路径，导入一条新商品；再打开文件选择窗口并取消，确认界面可继续操作。
5. 在内容工作室生成本地草稿，编辑、审核，并保存 Markdown/HTML。打开导出文件核对中文、商品事实和文件名。此步不调用模型。
6. 在设置页输入不少于 10 字符的测试口令，点击创建备份，再在保存对话框选择位置并保存 `.mgeobak`。随后修改测试商品，再选择备份恢复，确认恢复到备份时的内容；重启后再次检查。

## Mac → Windows 交叉恢复

请在 Mac 的测试工作区自行创建一个测试品牌与商品，导出加密备份，然后在 Windows 的测试工作区恢复，核对数据并退出重开。恢复会替换整个工作区并先创建安全快照，因此不要使用真实客户数据。恢复后模型需重新配置。公开发行附件不包含任何用户数据库或备份样例。
